# macOS handoff, 2026-11-12

For the Apple Silicon Mac. The Linux work is finished on threadripper (AMD
Ryzen 9 9950X, Alpine Linux edge 7.2.9). Pull bctl `main` at `1a87fc5` or
later, Hydrogen `main` at `e94a0d3f` or later, tinyland `main` at `5c5da46`
or later, Shadowdriver `main` at `3a5aeb5` or later, and stuff `main` at
`123814d` or later. Every check below ran on Linux only, so none of the
changes since `cbf338b` has been built or run on macOS.

## What changed that macOS must absorb

- **SmolVM 1.34.1** (`f5888fc`, re-imported at upstream `59bdcf62` in
  `4cdf300`). The libkrun bump, a host memory reserve, a cache-disk fix and
  the patched SQLite came with it. The graviola patch was rebased onto the
  rusqlite upgrade and now carries `p256.rs`, which had been committed into
  the vendored tree outside any patch.
- **New SmolVM patches.**
  - `smolvm-0004` gives Linux user mounts override-stat ownership. It is
    `cfg(target_os = "linux")` and changes nothing on macOS.
  - `smolvm-0005` turns off IPv6 duplicate address detection in the guest
    agent. It reaches the arm64 guest too, through the rebuilt agent rootfs.
- **`runtime/build.sh` and `runtime/guest.sh`** now select the host by
  `uname`. The `Darwin/arm64` branches keep their original commands, and the
  patch loop now also accepts a patch that cannot be reversed alone because a
  later patch edits the same lines (libkrun 0007 under 0008). The guest seatd
  is built from the tinyland archive at `guest/tinyland.rev` (`7284c0d`), so
  the guest container now needs network access to GitHub.
- **Images.** `images/build.sh` passes `GUEST_ARCH`, and the helium
  Dockerfile builds tinyland and seatd from the upstream context
  (`752707f`) at tinyland `5c5da46` (`5af3ec2`), which has the ten P2
  lifecycle fixes. aarch64 still requires a Helium r6 archive.
- **Behaviour.**
  - `bctl tab new URL` returns once the navigation commits (`2e8f043`).
  - An operator's CDP URL may attach while a run waits for a person, and
    resume closes it (`8d851bc`).
  - SmolVM is the default runtime on every host (`1a87fc5`). macOS already
    defaulted to it, so nothing changes there.
- **stuff.** The PyPI mirror now records musl targets, so a `stuff` or
  `mypypi` built before `123814d` refuses to plan against it. Run
  `make install` in `~/d/stuff` before publishing from the Mac.

## Do, in order

1. **Build the runtime.** `runtime/build.sh` must exit 0 and print
   `smolvm 1.34.1`, `smolvm 59bdcf62d769` and `+ 13 patch`. Run
   `FORCE=1 sh runtime/guest.sh` first, because the agent and seatd changed.
   Any failure in the Darwin branch is new since `81f3e29`.
2. **Build the image.** `BCTL_BROWSER_ARCHIVE=DIR images/build.sh helium`
   with the r6 arm64 archive.
3. **Run the checks** from `docs/runtime.md` "Tests": `cargo test
   --workspace`, the SmolVM lifecycle and restore suites, and the bctl VM
   suites `daemon`, `sessions`, `profiles`, `cdp`, `egress` (with
   `BCTL_TEST_IMAGE=ref-alpine-chromium`), `tabs`, `snapshots`, `actions`,
   `batches`, `authority`, `failures`, `media`, `native_cdp` and
   `host_http`. Run `runs` with `BCTL_GRAB` set.
4. **Run interop twice:** `sh tests/interop/run.sh`. Both runs should pass
   113 of 113. Then update the `mac-smolvm` row in `docs/compatibility.md`
   (it still says smolvm 1.34.0).
5. **Recheck Nanos on macOS** if it is still wanted. The arm64 pin in
   `runtime/build-nanos-arm64.sh` is Hydrogen `6dc7d43e`, which predates
   the Linux kernel repairs (`5ece982a`, `e4aad9cc`, `0523dbbc`). Move it to
   `44f4b61f`, rebuild with `runtime/build-nanos-krun.sh`, and rerun
   `BCTL_RUNTIME=nanos sh tests/interop/run.sh`.
6. **Open macOS ticket:** BCTL-9, where a macOS Nanos startup timeout can
   leave the libkrun runner running.

## Known open items that are not macOS-specific

- BCTL-10 (P3): the web UI has no tone for paused sessions.
- BCTL-14 (P3), if still open when you read this: a command right after a
  daemon restart can fail with a connection reset.
- Hydrogen HYD-3 and HYD-4 stay open on 2,400 clean loop cycles; the long
  loops were relaxed.
- Shadowdriver SHD-30: `grab verify` fails pages under host load, which
  makes the `runs` suite flaky on a busy machine.
- Tinyland TINY-11 to TINY-13 (P3).
- M7H, headed Nanos, is superseded by headed SmolVM on Linux; see the
  roadmap.
